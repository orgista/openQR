The OpenQR "Corner" mark and app icon, generated by `branding/build_icons.py`. `openqr-mark.svg`: `brand-ink` brackets for dark grounds. `openqr-mark-dark.svg`: `brand-tile-bottom` brackets for light grounds. `openqr-app-icon.svg`: the rounded graphite tile (rx 232/1024). `openqr-app-icon-square.svg`: the square tile for store art. The core gradient is part of the mark: never flatten or recolour it.
